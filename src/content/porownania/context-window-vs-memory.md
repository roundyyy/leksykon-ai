tytul: Context window vs memory
hasla: [context-window, memory]
kolejnosc: 30
---

Context window to ilość materiału znajdującego się w bieżącym „polu widzenia” modelu. Memory jest mechanizmem przechowywania informacji poza tym oknem i ponownego ich wprowadzania, gdy będą potrzebne. Milion tokenów kontekstu nie oznacza automatycznie trwałej pamięci.
