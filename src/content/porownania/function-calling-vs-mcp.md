---
tytul: Function calling vs MCP
hasla: [function-calling, mcp]
kolejnosc: 40
---

Function calling mówi modelowi, jak poprosić o wykonanie określonego narzędzia. MCP standardyzuje sposób, w jaki całe zestawy narzędzi, danych i innych możliwości są wystawiane klientom AI.

Function/tool calling to mechanizm, dzięki któremu model mówi „chcę uruchomić narzędzie X z argumentami Y”. MCP to **standard komunikacji i wystawiania takich narzędzi oraz danych pomiędzy systemami**. Narzędzia MCP mogą być następnie wywoływane przez model. W 2026 r. MCP jest już wspierany przez duże platformy i aktualna rewizja protokołu to 2026-07-28.
