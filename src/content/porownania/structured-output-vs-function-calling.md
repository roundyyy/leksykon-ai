---
tytul: Structured output vs function calling
hasla: [structured-output, function-calling]
kolejnosc: 120
---

Structured output określa format odpowiedzi modelu; function calling służy do komunikowania zamiaru użycia narzędzia. Dokumentacja OpenAI wprost zaleca function calling, gdy model ma łączyć się z funkcjami lub danymi systemu, i structured output, gdy chodzi o strukturę samej odpowiedzi.
