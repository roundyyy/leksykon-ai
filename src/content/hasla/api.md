Zestaw reguł umożliwiających jednemu programowi komunikację z innym programem lub usługą.

W kontekście AI API pozwala np. wysłać zapytanie do modelu, przekazać dane, ustawić parametry przetwarzania i odebrać odpowiedź bez konieczności uruchamiania modelu lokalnie.

API nie jest technologią specyficzną dla sztucznej inteligencji.
