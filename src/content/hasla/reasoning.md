W języku produktów AI oznacza zwykle model lub tryb, któremu przydziela się dodatkowe obliczenia na rozwiązanie wieloetapowego problemu przed sformułowaniem finalnej odpowiedzi. Nie oznacza to naukowego dowodu, że system „rozumuje” identycznie jak człowiek.

Współczesne API jawnie operują np. budżetem lub poziomem *reasoning effort*.
